# API

API предоставляет доступ к основным функциям рекомендательной системы фильмов.

## Основные операции

- `POST /recommendations` — сформировать персональную подборку фильмов на основе предпочтений пользователя.
- `GET /recommendations/{userId}` — получить подборку рекомендаций указанного пользователя.
- `GET /movies/{movieId}` — получить информацию о выбранном фильме.

## Спецификация OpenAPI

Полное описание параметров, тел запросов, ответов, ошибок и схем находится в файле [`openapi.yaml`](openapi.yaml).
