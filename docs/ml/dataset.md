# Data Sheet

## Общая информация

- **Название:** MovieLens `latest-small`.
- **Источник:** [каталог MovieLens в TensorFlow Datasets](https://www.tensorflow.org/datasets/catalog/movielens) и [страница MovieLens от GroupLens](https://grouplens.org/datasets/movielens/).
- **Назначение:** данные об оценках фильмов и метаданных для учебного прототипа рекомендательной системы и проверки качества рекомендаций.
- **Тип:** табличные данные о фильмах и пользовательских оценках.
- **Использование:** набор рассматривается как источник данных для прототипа и тестирования. Он не использовался для обучения выбранной языковой модели.

## Состав данных

По документации TensorFlow Datasets, `latest-small` содержит:

- **100 836 оценок**;
- **9 742 фильма**;
- **610 пользователей**;
- оценки собраны с 29 марта 1996 года по 24 сентября 2018 года;
- демографические данные в этой версии отсутствуют.

Основные поля:

| Поле | Описание |
|---|---|
| `movie_id` | Уникальный идентификатор фильма |
| `movie_title` | Название фильма, обычно с годом выпуска |
| `movie_genres` | Один или несколько жанров |
| `user_id` | Идентификатор пользователя в наборе |
| `user_rating` | Оценка по пятибалльной шкале с шагом в половину балла |
| `timestamp` | Время выставления оценки в формате Unix timestamp |

Размер файлов может зависеть от способа загрузки и представления данных. При фактическом использовании следует зафиксировать выбранную конфигурацию и дату загрузки.

## Получение данных

1. Открыть [каталог MovieLens в TensorFlow Datasets](https://www.tensorflow.org/datasets/catalog/movielens).
2. Выбрать `latest-small-ratings` для оценок либо `latest-small-movies` для каталога фильмов.
3. Загрузить данные средствами TensorFlow Datasets или получить архив с официальной страницы MovieLens.
4. Перед использованием прочитать условия использования в README выбранного набора.

Официальная документация указывает, что `latest-small` может обновляться. Для воспроизводимости эксперимента нужно зафиксировать конкретную версию и дату загрузки.

## Предобработка

Планируемые шаги:

1. Проверить пропуски и дубликаты.
2. Проверить связь оценок и каталога по `movie_id`.
3. Нормализовать жанры и привести их к согласованному написанию.
4. Определить обработку записей без жанров.
5. При оценке качества разделять данные на обучающую и тестовую части до расчёта пользовательских предпочтений.
6. При временном тестировании использовать ранние события для построения профиля, а более поздние — для проверки.
7. Не включать `user_id` в публичные ответы API.

Это план предобработки; до фактической загрузки данных нельзя утверждать, что шаги уже выполнены.

## Ограничения

- Набор содержит названия, жанры и оценки, но не синопсисы фильмов. Поэтому он не подходит для полноценной проверки рекомендаций на основе сходства сюжетов.
- Данные исторические: последняя дата оценок в `latest-small` — сентябрь 2018 года.
- В наборе представлены пользователи MovieLens; их предпочтения могут отличаться от предпочтений аудитории будущего приложения.
- Жанров может быть недостаточно для точных рекомендаций.
- Из-за отсутствия демографических данных в этой версии нельзя надёжно оценить качество для разных демографических групп.
- Доступная документация не подтверждает репрезентативность набора для русскоязычной аудитории.
- Перед распространением данных или их частей необходимо соблюдать условия использования GroupLens.

## Использование в проекте

MovieLens можно использовать для:

1. Проверки логики рекомендаций по жанрам и, при необходимости, учёта оценок.
2. Оценки рекомендаций на отложенных данных с помощью `Precision@K`, `Recall@K` и `NDCG@K`.

Модель `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` не обучается на этом наборе в рамках данной работы. Она может кодировать названия и жанры в эмбеддинги; оценки обрабатываются отдельной логикой проекта.
