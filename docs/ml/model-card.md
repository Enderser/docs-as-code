# Model Card

## Общая информация

- **Название:** `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`
- **Источник:** [Hugging Face Hub](https://huggingface.co/sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2)
- **Автор / организация:** Sentence Transformers.
- **Задача:** преобразование предложений и коротких текстов в векторные представления (эмбеддинги) для сравнения семантически похожих текстов.
- **Языки:** мультиязычная модель, поддерживающая 50+ языков.
- **Лицензия:** Apache-2.0.
- **Размерность эмбеддинга:** 384.
- **Максимальная длина последовательности:** 128 токенов.
- **Обучающие данные:** модель описана как мультиязычная версия `paraphrase-MiniLM-L12-v2`, обученная на параллельных данных для 50+ языков. Полный перечень и точный объём обучающих данных в карточке выбранной модели не приведены.

## Использование в проекте

Проект — рекомендательная система фильмов. Модель не является готовой рекомендательной системой и не предсказывает рейтинг фильма напрямую. Она может использоваться как компонент контентной рекомендации:

1. Для каждого фильма формируется текст из названия и жанров.
2. Модель преобразует этот текст в эмбеддинг.
3. Из выбранных пользователем жанров формируется текст предпочтений, который также преобразуется в эмбеддинг.
4. Эмбеддинги сравниваются по косинусному сходству, после чего фильмы ранжируются.
5. Система может исключать уже просмотренные фильмы, если такая информация доступна.

В MovieLens нет описаний сюжетов. Поэтому в базовом варианте модель сравнивает только названия и жанры, а не содержание сюжета, актёрский состав или визуальные характеристики.

## Входные данные

- Текстовое представление фильма: название и список жанров.
- Текст пользовательских предпочтений: выбранные жанры или короткая формулировка интересов.
- Перед сравнением текстов рекомендуется привести значения к согласованному формату.

Модель не принимает таблицу рейтингов как готовую рекомендацию. Рейтинги MovieLens используются отдельной логикой проекта для построения профиля или проверки качества.

## Выходные данные

- Вектор размерности 384 для каждого входного текста.
- Векторы можно сравнивать с помощью косинусного сходства.
- Значение сходства не является вероятностью того, что пользователь посмотрит фильм или поставит ему высокую оценку.

## Метрики качества

- В карточке модели не указана единая метрика, измеряющая качество рекомендаций фильмов именно в нашем проекте.
- Показатели модели в других задачах нельзя автоматически считать показателями качества рекомендательной системы.
- Для проверки проекта предлагается оценивать `Precision@K`, `Recall@K` и `NDCG@K` на отложенных данных.
- Фактические значения этих метрик пока **не измерены** и не приводятся как достигнутые результаты.

## Ограничения

1. **Ограничение модели:** она создаёт эмбеддинги текста, а не готовые рекомендации. Алгоритм ранжирования и правила фильтрации нужно реализовать отдельно.
2. **Ограничение модели:** максимальная длина последовательности в конфигурации — 128 токенов; длинный текст может быть усечён.
3. **Потенциальное ограничение для нашего проекта:** если у фильма есть только название и жанры, модель не сможет учитывать сюжет, режиссёра, актёров и другие отсутствующие признаки.
4. **Потенциальное ограничение для нашего проекта:** текстовое сходство не обязательно совпадает с личными предпочтениями пользователя.
5. **Потенциальное ограничение для нашего проекта:** качество может различаться между языками; мультиязычность не гарантирует одинаковую точность для русских и английских текстов.
6. **Потенциальное ограничение для нашего проекта:** если каталог англоязычный, а предпочтения вводятся на русском, качество сопоставления необходимо отдельно проверить.

## Не рекомендуется использовать

- Как единственный источник рекомендаций без проверки на тестовых данных.
- Для вывода, что пользователь обязательно посмотрит фильм или поставит ему высокий рейтинг.
- Для рекомендаций по содержанию сюжета, если доступны только название и жанры.
- Для психологических выводов о пользователе по истории просмотров.
- Для сравнения версий системы без одинакового тестового набора и зафиксированных метрик.
