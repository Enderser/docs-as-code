# Рекомендательная система фильмов

Сервис анализирует предпочтения пользователя и рекомендует фильмы, которые могут ему понравиться. Система учитывает жанры, оценки ранее просмотренных фильмов и интересы пользователя, чтобы формировать персональную подборку.

**Основные пользователи:**

- пользователь.

**Основные функции:**

- указание предпочтений по жанрам и оценка просмотренных фильмов;

- подбор персональных рекомендаций на основе предпочтений пользователя;

- просмотр информации о фильмах: описание, жанр, год выпуска и рейтинг;

- добавление фильмов в список «Посмотреть позже».

## Комплект документации

1. **Описание проекта** — предназначено для участников команды и заказчиков, чтобы определить назначение системы, её цели и основные функции.
2. **Технические требования** — предназначены для разработчиков, чтобы зафиксировать функциональные и нефункциональные требования к рекомендательной системе.
3. **Архитектура системы** — предназначена для разработчиков и системных архитекторов, чтобы описать структуру приложения, взаимодействие компонентов и используемые технологии.
4. **Документация API** — предназначена для разработчиков, чтобы описать способы взаимодействия между клиентским приложением, сервером и базой данных.
5. **Документация ML-модели** — предназначена для ML-инженеров и разработчиков, чтобы описать алгоритм рекомендаций, используемые данные, процесс обучения и оценку качества модели.
6. **Описание структуры базы данных** — предназначено для разработчиков и администраторов баз данных, чтобы определить формат хранения информации о пользователях, фильмах, оценках и рекомендациях.
7. **Руководство пользователя** — предназначено для пользователей системы, чтобы объяснить, как указывать предпочтения, получать рекомендации и сохранять фильмы в список просмотра.
8. **Инструкция по установке и развёртыванию** — предназначена для разработчиков и DevOps-инженеров, чтобы обеспечить правильную установку, настройку и запуск системы.
